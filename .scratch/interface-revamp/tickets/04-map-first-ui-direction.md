## Resolution

On 2026-10-14 the human accepted the B direction: a main Dock, optional true Hierarchy, icon catalogue and the Fields flow. On mobile, Inspect and Hierarchy are fullscreen and mutually exclusive; desktop keeps the map independently navigable beside panels. Remove the decorative map utility row and LIVE MAP badge. Preserve session drafts, focus, selection and context through hide/reopen and responsive reflow.

The accepted disposable source was `7ea41e0a9b0e585e23812eb9165e95420d72dc89`. Targeted browser checks supported the presentation choice; they did not establish full product parity, physical-device behavior, accessibility or performance acceptance.
