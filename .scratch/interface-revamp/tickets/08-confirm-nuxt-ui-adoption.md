## Resolution

On 2026-10-16 the human selected Nuxt UI as the primary production interface library, using its components as much as practical. Adapt/configure a suitable component before considering custom UI; any exception must be the smallest surface needed to preserve a requirement, with its reason and validation recorded.

This does not promote the prototype as the product. D3/SVG rendering, domain commands, draft/session state, persistence and JSON/image interchange remain application-owned. All accepted interaction, preservation, accessibility and export contracts remain in force.
