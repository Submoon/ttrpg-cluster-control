## Resolution

Resolved on 2026-10-15 through the human's explicit live answers to Q1–Q10 and request for desktop right-button pan. This is the only decision ticket resolved in this Wayfinder session. ### Intents and panel boundaries

| Intent | Confirmed behavior |
| --- | --- |
| Navigate | Default camera mode. Drag pans, including over entities, without geometry edits. A deliberate short system activation opens its separate system map without opening Inspect. No separate Pan tool is added. Existing selection behavior for other targets remains. |
| Select | Persistent data-editing intent. Short entity activation selects and requests Inspect through the draft guard; a system opens its data rather than its map. Drag pans even over an entity and does not open Inspect on release. |
| Move | Persistent direct manipulation of existing geometry under the prior object/system/Orbit and attachment rules. Target activation selects rather than entering a system. Background pan remains available. |
| Add | Persistent creation intent, separate from moving existing entities. Choose a context-appropriate type, then place it under the existing target, validation and ambiguity rules. A successful creation leaves Add ready for another of the same type. |

Inspect and Hierarchy remain panels with expanded states, separate from the active map intent. Opening, hiding or reopening Inspect does not itself change the active mode. Numeric coordinates, radii and rotation remain editable in Inspect while Select is active; Move is not a geometry permission lock. Validation and targeted draft exclusion apply to both forms and map commands.

### Repeated Add and exit

- Keep the chosen type after each successful placement; do not reopen the catalogue for every creation. A completed Jump Route starts a fresh route, with no previous endpoints accidentally reused. Creating a system leaves the cluster map open with Add System active.
- Successful creation never forces Inspect open. Editing remains on demand through Select, explicit Inspect, or the established inspection paths. An already-open or hidden editor draft is preserved; this decision does not silently retarget or discard it.
- Distinguish catalogue dismissal from Quit Add. Dismissing the chooser retains the chosen creation intent. Escape on the map or visible Quit Add abandons only the unfinished creation and returns to Navigate; completed creations and inspector drafts survive. Existing dialog/focus handling must not let the same key implicitly discard unrelated work.
- Invalid/ambiguous targeting retains Add and requires the existing explanation/explicit choice before publication. Keep a visible active type and current target/progress, including route endpoint stage, plus an explicit exit. Exact layout/text belongs to the presentation decision; generic pan-only guidance is insufficient while Add is armed.
- Creating an entity and later editing its data are distinct applications. Inspector Discard drops its unapplied edits; it does not delete the previously placed entity. Existing draft conflicts and guarded selection changes remain authoritative.

### View navigation during editing and creation

- Two-contact pan/zoom remains view-only in every mode. Right-button hold plus drag adds desktop view pan in every mode, including over entities and handles in Move and placement targets in Add. It retains the mode/type and cannot move an entity, place one, trigger Inspect/context entry, or open a context menu as a side effect of the pan gesture.
- View takeover cancels an uncommitted geometric gesture preview before navigating and must suppress later release/click publication from that canceled gesture. It does not undo earlier committed changes or discard inspector drafts.
- A chosen Jump Route origin is multi-step operation progress, distinct from a live gesture preview. Two-contact/right-button pan preserves that origin and current creation stage while canceling only the transient gesture preview. Escape / Quit Add abandons the entire unfinished route. No partial route is committed by panning.
- Preserve one-finger direct editing in Move, wheel zoom, the existing long-press inspection in Navigate/Move with cancellation before Inspect and follow-up-click suppression, explicit Inspect, and complete keyboard/single-pointer alternatives. No new long-press binding in Add is inferred. Selection, mode and panel state remain separate.
