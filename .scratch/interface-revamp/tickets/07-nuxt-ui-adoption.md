## Resolution

On 2026-10-13 the human authorized broad Nuxt UI use in a disposable prototype to judge a consistent interface foundation across realistic editor flows. Adapt suitable primitives first and document any focused exception. This was an experiment, not production adoption; ticket 08 records the later decision.

The application retains D3/SVG maps, domain validation, draft ownership, persistence and interchange. Evaluate SSR/hydration, focus, keyboard/touch behavior, local resources, portal themes and production cost in the integrated application; library defaults alone do not establish those guarantees.
