## Existing behavior and risks

`useLocalWorkspace` is the sole page persistence owner: `commit` validates/detaches, publishes memory immediately, queues durable writes, and uses a revision to stop old completions changing newer status. However, its async signature hides synchronous acceptance, and forms await durability before ending. No save Retry exists. Hydration Retry reads disk; it must never replace a save retry. Backup restore already publishes only after durable replacement.

`useEditorState` owns chart strings/errors, but watches committed names into those strings unconditionally; target identity follows selection. Its guard is synchronous discard/refuse, treats even clean editing as modified, and cancels all editors. Cluster/map/Fields/file workflows consume that boolean; several capture workspace/system before guarding. Chart Apply then navigation could therefore overwrite the applied name with a stale candidate. `ChartDetailsPanel` and `MapHierarchy` duplicate presentation over shared strings. MapEditorLayout hides mounted panels with `v-show`. Footer currently mixes draft and durability feedback. JSON exports already serialize applied memory with existing codecs.
