## Corrected composition contract

Preserve the approved structure above while using Nuxt UI appearance and components. Keep the real persisted product, single UApp/theme integration, modes, context guards, independent cameras, scoped cancellation and truthful save recovery. Desktop overlays remain nonmodal and independently usable; compact Inspect/Hierarchy remain fullscreen/exclusive, hiding Dock/zoom, with unchanged editor instances across hide/reflow and correct focus entry/return. Do not promote prototype code or data.

Fit must use actual measured unobscured regions around panels, application/map chrome, bottom Dock/zoom and feedback. Recompute available geometry after panel size/visibility or viewport changes; never substitute fixed header/panel offsets. Presentation changes retain camera memory; explicit Fit supplies target recovery. Validate ordinary hit-tested target reachability rather than SVG dimensions alone.

Nuxt UI supports overlay placement and resizing as separate concerns. Installed `UDashboardGroup` exposes `persistent:false` and `unit:'px'`; `UDashboardPanel` exposes `resizable`, bounds/default size and a resize-handle slot. Its resize logic defaults to the left side; `UDashboardSidebar` exposes explicit `side:'left'|'right'` and passes that to `useResizable`. A supported nonpersistent group can therefore provide session-only dimensions. Stable slot content plus CSS positioning can supply overlays; the library does not require consuming layout columns.

Before selecting a resize adapter, verify the right panel's inward-edge delta direction and handle placement. Sidebar's desktop/mobile slot branches must not instantiate duplicate editors; a permanently closed menu with the retained main subtree is a candidate requiring proof. `UDashboardResizeHandle` supplies separator markup, not complete keyboard size controls: keyboard adjustment and accessible values need an adapter. None of this is implemented or runtime-validated by this report. Keep the already proven warning against changing Slideover `modal` across breakpoints, which remounts keyed Reka content. Prefer configured library primitives before a small justified resize/focus adapter; no persistent layout or generic state engine.
