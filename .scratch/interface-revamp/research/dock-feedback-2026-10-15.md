## Confirmed findings and design

- The canvas drops the chosen pointer location when emitting an Orbit target. The workbench then assigns `Math.PI / 5` for every newly attached mark. Preserve the target angle, computed from the raw SVG scene point and the existing resolved Orbit geometry helpers, including pan/zoom, rotation and nested hosts. Do not use the normalized/clamped free-placement helper for this calculation, change the saved domain format, or choose random positions.
- Move Hierarchy / Inspect into map chrome beside Map files, with responsive wrapping and visible state. Preserve Back to Jump Cluster, exclusive full-height mobile panels, draft guards and the hidden dock/zoom while a mobile panel is open.
- Use a controlled Nuxt UI Popover around the actual Add trigger. Its content contains the initial creation choices and then the catalogue. The installed Nuxt UI 4.11.3 component API is the implementation reference. Keep inherited prototype theme variables through the portal target, constrain width/height to available space, and let collision handling position the content instead of viewport-specific absolute offsets.
- Dismissing the chooser preserves mode/type/progress and editor drafts. Escape dismisses that layer before the map can quit Add; dialogs remain higher priority. An outside click used to dismiss the chooser must not also place a mark on the map. Opening Inspect/Hierarchy closes the chooser without resetting the active tool.
