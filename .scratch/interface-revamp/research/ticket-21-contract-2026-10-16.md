## State and command boundary

Own session-only mode (`navigate | select | move`), panel visibility and map visit memory above presentation. Keep cluster/system context separate from an inspected cluster-system target. Use explicit activation callbacks; never infer behavior from an accessible label. Map callbacks and hierarchy commands must reach the same guard/selection authority.

- Navigate: short system click/tap/Enter/Space enters its map, without forcing Inspect. Other targets retain selection behavior; drag over any entity pans without geometry writes.
- Select: short entity activation selects and requests Inspect; a cluster system exposes its existing name/summary data while staying in the cluster. Drag over entities pans and never requests Inspect on release.
- Move: activation selects existing targets without system entry; enable current validated geometry gestures and retain background pan. Numeric legacy forms remain usable independently of this mode.

Add remains functional legacy creation behind a separate labeled entry, preferably UPopover hosting the current catalogue/cluster actions. Do not represent the chooser as an armed persistent placement tool; ticket 23 owns that actual behavior. Preserve all existing catalogue/Orbit/route commands, not placeholder buttons. If moving catalogue controls would break retained drag support, keep the smallest functioning adapter and document it. No new global shortcuts or application context menu.

Preserve ticket 20's asynchronous guard, captured IDs/context rechecks and honest legacy Discard/Stay adapters. Selection/context requests await acceptance before changing mode, panel visibility or selection. Return explicit accepted/refused results where composition needs to know whether Inspect may open. One explicit accepted-context boundary snapshots outgoing UI state, changes context, restores incoming valid selection/camera and resets Navigate; use it for legacy creation/import assignments too, rather than relying on later watchers to capture an already changed context. Stay/invalid Apply changes none of those. Apply/save ordering and delayed import navigation protection remain intact. A same-map Inspect/Hierarchy toggle preserves mode and drafts; hiding is never Discard. Existing independent map movement remains available while a draft is hidden; reject a known owned-target manipulation before its editable preview, using existing inspector identity checks rather than a new dependency engine.

## Stable Nuxt UI composition

Installed Nuxt UI 4.11.3 offers UButton/UPopover/UDashboardPanel and Slideover `unmountOnHide`, `modal`, `portal`, `side` and content hooks. **Do not bind Slideover.modal to compact mode:** installed Reka DialogContent switches keyed Modal/NonModal subtrees, remounting inspectors despite `unmountOnHide:false`; NonModal also hardcodes `trapFocus:false`. DashboardSidebar duplicates desktop/mobile slots and is unsuitable for retained local forms.

Choose stable UDashboardPanel instances with `resizable:false`, `v-show` and one existing editor subtree each; adapt slots/styles for the selected Dock composition. It has a local dashboard-context fallback and useResizable creates storage only for resizing/collapsing: this configuration adds no provider/cookie/layout persistence. Override its default `min-h-svh` through supported UI slots to fit the measured containing area. Use the installed Reka FocusScope around the same subtree, changing `present`/`trapped` without branching. Add explicit `reka-ui: 2.10.5` dependency if importing it directly. This narrowly justified panel composition preserves drafts while reusing library content, controls and focus handling.

Use FocusScope's supported `as-child` on the single existing `.map-editor-layout` root. Its default Primitive otherwise inserts an unconstrained div between the flex parent and the viewport-sized grid, breaking the definite-height chain. Installed Slot forwarding preserves the root DOM identity, attributes, ref and keydown/focus behavior; do not alternate wrapper shapes at runtime or remount the retained panel subtrees.

Use one compact query `(max-width: 760px), (max-height: 600px)` for both state and CSS: 844×390 is compact regardless of device identity. Compact panels occupy available fullscreen height, slide from bottom, contain scrolling, show named Hide/Close, trap focus and make underlying map/header/Dock inert. A single panel command coordinator enforces Inspect/Hierarchy exclusivity for Dock, hierarchy row, Select, long press, explicit Inspect, reopening and reflow. On desktop both panels are independently nonmodal. Reflow retains the most recently requested panel when both were open; does not remount forms. Focus stays within retained work, and Hide returns to the actual opener or an appropriate visible fallback. New modal/popover layers must pause the underlying focus scope, consume dismissal first, and remain operable above panels. Reduced motion removes slides, not opening/reopening controls.

Keep hierarchy/Inspect commands adjacent to Map files; use UPopover/appropriate menu slots for files in a portal above desktop panels, with keyboard entry/return and normal hit testing. Keep the theme provider and scoped Fields/chart dialogs. Reserve real layout rows for compact context/Back, feedback and Dock/zoom, and desktop columns for open panels; avoid old absolute offsets and menu-inside-lower-stacking-context traps. Long names remain accessible without a tall secondary-summary header. Fit uses the actual remaining drawable rectangle, converted through SVG screen matrices, with matching D3 extent; chrome is not counted as drawable space. Recovery controls must expose actual targets at short height without forced clicks. One zoom set offers range feedback, +/-/Fit and named single-pointer pan; keyboard view commands apply when the map is focused and protect text inputs/geometry controls.

Use semantic palette styles for new Nuxt controls/focusable SVG marks: opaque `var(--focus)` outline, adequate offset and no competing translucent ring. Configure component slots/classes or a focused shared class, not scattered control patches. Measure complete unobscured outlines, useful text >=4.5 and meaningful controls/graphics >=3 against actual composited backgrounds in both themes. Distinguish pressed mode, expanded panel, selection and focus beyond color.

## Addendum: rename the inspected system by identity

Cluster Inspect may show system B while last active system remains A. Extend `beginChartNamesEdit(targetSystemId?: string)` and forward `'edit-chart-names': [targetSystemId?: string]` without dropping the payload. A system-details trigger emits its displayed system ID; generic/resume triggers deliberately pass no argument, never a native click event. No argument resumes the existing session; only without a session may it default to the active system. Explicit same-target requests resume exact values/errors. Explicit different-target requests resolve the existing session through the current guard, then revalidate captured cluster/target and originating inspection context against latest memory before starting another. Stay/invalid Apply preserves the original session; missing B refuses rather than falling back to A or the first system. Apply continues using the session's captured ID.
