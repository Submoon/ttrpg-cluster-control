### Agreed shared contracts

- One source/full-map version 4 introduces both slices; layout and internal player DTO remain version 1. Keep existing `description` as private GM notes, with required empty-by-default `playerText` and `playerFieldMasks` on source objects. Prior source versions receive only their version-authorized defaults, preserving v2 system and v3 object strictness; v4 requires current metadata.
- Custom definitions have `playerShared`; native Fields have `nativePlayerSharing` in the existing Field settings. New/legacy sharing defaults false. Masks contain existing custom definition IDs or reserved native IDs. Validate references/duplicates, retain inactive masks and remap custom masks on independent import. Removing a definition removes its masks.
- Definition publication and object masks remain distinct. Projection requires Revealed object, applicable shared Field, assigned value and no object mask. Published values contain only name/type/value; no options, source definition identity or applicability inventory. Player text never substitutes GM notes.
- Same-name custom reuse requires matching publication policy and existing type/options; shared definitions also require equal canonical applicability to avoid broadening inactive assignments. Private definitions retain the established applicability union. Conflicting custom/native policies fail explicitly before mutation through the existing import error path, with instructions to align policies. No new import-decision subsystem is needed.
- `JumpRoute.playerShared` defaults false. Existing create/update APIs gain final optional sharing arguments, preserving current flags on unrelated edits. Route drafts and Field/object snapshots, dirty signatures, accepted mutations and history include their new settings.
- Public routes contain only public ID, Jump level, public origin system and either a public destination system or generic unknown destination position. Allocate public route IDs after filtering. Resolve full-source applied external-exit positions before filtering; resolved Hidden endpoints retain exact authorized system coordinates. Reverse the public origin when needed without altering source orientation. Derive public paths, labels and bounds from the projected graph only.
- Only a Revealed Jump Point with a Revealed linked Station receives a remapped public Station reference. Associations never retain/promote otherwise Hidden objects.
- Disjoint writers handle both tickets concurrently by layer: domain/formats/projection and new pure tests; editor/controllers/components, public-only geometry and new browser journeys. The coordinator retains shared fixtures/helpers, BaselinePage, documentation and shared checks. Initial pure and browser tracers are written and frozen before feature implementation, followed by vertical red/green slices.
